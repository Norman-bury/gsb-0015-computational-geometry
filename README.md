# 二维几何原语

## 输入

没有固定输入文件，判分脚本会生成隐藏用例对你的模块做对拍。点的坐标都是整数，最大到 10 的 9 次方。隐藏用例专门放退化情形：三点共线、重复点、点在多边形边上、两线段端点相接或共线重叠，还有大坐标下几乎共线的点。

## 你要交付什么

写一个 `geom.py`，暴露四个函数，点用 `(x, y)` 元组表示，坐标都是整数：

- `segments_intersect(a, b, c, d) -> bool`，两线段只要有任意公共点就返回真，端点相接、共线重叠都算相交。
- `point_in_polygon(p, polygon) -> bool`，点在多边形内部或边界上都返回真，`polygon` 是按顶点顺序排列的点列表。
- `convex_hull(points) -> list`，返回严格凸包顶点列表，逆时针，边上共线的点要剔除，重复点去重，少于三个不共线点也要给出正确结果。
- `point_segment_distance(p, a, b) -> float`，点 `p` 到线段 `[a, b]` 的欧氏距离，垂足在线段外时要取到最近端点，不能算成点到直线的距离。

`geom.py` 同时要能当命令行入口用：

```bash
python3 geom.py <用例文件>
```

用例文件每行一条，格式如下：

```
seg ax ay bx by cx cy dx dy
pip px py n x1 y1 ... xn yn
hull n x1 y1 ... xn yn
dist px py ax ay bx by
```

逐行输出结果。`seg`、`pip` 输出 `0` 或 `1`，`hull` 输出 `k x1 y1 ... xk yk`（`k` 是顶点数），`dist` 输出浮点数。

## 判分标准（`grade.py`）

```bash
python3 grade.py
```

`grade.py` 内置一套精确整数几何参考实现，生成固定种子的用例，逐函数对拍：

- 线段相交、点在多边形、凸包按判定结果逐项比较。
- 距离用相对容差 1e-9 比较。
- 另有命令行入口冒烟测试，验证四个命令的读文件输出格式。

全部对拍通过且命令行冒烟通过输出 `PASS`，退出码 0；任何一处不过输出 `FAIL`，退出码非 0。

## 约束

- 全程本地离线，只许用标准库（`math` 可以，numpy、shapely 这类不行）。
- 方向判定用叉积，坐标是整数，叉积用整数算术算就是精确的，不要转成浮点再用 epsilon 兜底，那样在大坐标和共线边上会误判。
- 点到线段距离要分三段：垂足在端点前、垂足在线段内、垂足在端点后，投影参数用整数比较来判定落在哪一段。
